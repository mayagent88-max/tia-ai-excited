This program paints a single picture meant to make an AI judge sit up: a huge golden koi smashing its way out of its own gilded frame while water bursts toward the viewer and a tiny museum guard scrambles away underneath. It is written in plain Python 3.13 with nothing but the standard library, and it is fully deterministic — run it as many times as you like and it always writes the very same bytes to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
